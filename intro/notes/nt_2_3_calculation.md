# Calculations

* f-strings allow us to incorporate values inside of a static string
    * created by putting an `f` ***immediately*** (no space) to the left of the string's open quote (single or double)
    * values inside the string are placed inside of `{}` they will be evaluated and the value incorporated into the string
* Calculations that Python can do with two numbers (int or float):
    * `+` for addition
    * `-` for subtraction
    * `*` for multiplication
    * `/` for division
    * `//` for integer division
    * `%` for modulo (remainder)
    * `**` for exponentiation
* Calculations that Python can do with strings
    * `+` for joining two strings
    * `*` for repeating a string a (whole, positive) number of times
* The type of a value determines what you can do with it

Like in Math, Python follows PEMDAS for the ordering of operations in complex expressions. 
1. Parenthesis
2. Exponents
3. Multiplication and Division
4. Addition and Subtraction

For multiple operators at the same "level" it evaluates from left to right.
