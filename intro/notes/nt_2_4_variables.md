# Variables

The purpose of variables is to:
* remember something (for later use)
* reduce repetition: by not having to calculate something multiple times (because you remembered it)
* make the code easier to update: because values that are used in many places are created in **one** place
* makes the code more readable: a value is replaced by a name that indicates what it represents

variables syntax: the variable name *must* be on the left side of the equals
```
variable_name = variable_value
```

Naming rules for variables:
* Cannot be a reserved keyword (a word that means something to Python)
* Cannot *start* with a number (but it can have a number in it)
* No punctuation, delimiters, or special characters
* No spaces

Appropriate variable names should adequately describe the thing they are meant to represent
